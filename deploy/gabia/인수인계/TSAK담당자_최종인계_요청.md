작성 2026-11-20
**요청은 하나입니다: 마무리를 끊지 말고, 완료 시점에 아래 3가지를 남겨주세요.**

## 요청 사항 (완료 시점에 남겨주실 것)

### ① 최종 소스 버전

어느 커밋이 최종인지 **한 줄로** 특정해 주세요.

```
예시) flutter_app  e17df01  (2026-11-20)
      gabia_deploy  9d4ba48  (2026-11-20)
```

이유: 저장소가 3곳으로 나뉘어 있고, 그중 `gabia_deploy` 는 **원격이 없습니다.**
"최신"이라는 말만으로는 나중에 어느 상태였는지 재현할 수 없습니다.
커밋 해시가 있으면 그 시점을 그대로 되살릴 수 있습니다.

> ⚠️ 참고: `deploy/nas_proxy/` 사본이 1년 전 코드로 남아 있던 사고가 있었습니다
> (585KB vs 실제 1,450KB). 사본은 조용히 낡으므로 **해시로 못 박는 것**이 안전합니다.

### ② 실행 방법

다른 사람이 아무 설명 없이 따라 할 수 있는 수준으로 부탁드립니다.

- 필요한 패키지 (**`openpyxl` 포함** — 종전 문서에는 "불필요"라고 잘못 적혀 있었습니다)
- 환경변수 4개: `TSAK_PORT` / `TSAK_STATIC_DIR` / `TSAK_APP_ROOT` / `TSAK_STATE_DIR`
- 시작 명령
- 상태 디렉터리가 **릴리스 밖**에 있어야 하는 이유

### ③ DB 와 첨부파일의 백업 및 복구 절차

- 무엇이 정본인지 (NAS 경로)
- 백업이 어디에 몇 개 쌓이는지 (현재 `backups/` **432개**)
- 복구 명령과 **걸리는 시간**
- 복구했을 때 **무엇이 되살아나고 무엇이 안 되는지** (한계까지)
- 이전할 때 실제로 옮겨야 하는 것 (현재 파악: `merch_img_upload` 80MB + 세션)

## 참고 — 진행 중인 마무리 작업 상태

### ① 준비 완료 (실행해서 확인한 것)

| 항목 | 확인 근거 |
|---|---|
| NAS TLS 인증서 고정 | 실 NAS 접속 14항목 / 한글 포함 쓰기·읽기 왕복 일치 / **틀린 지문 차단 확인** |
| 업로드 유실 버그 | 수정 전 `IndexError` 재현 → 수정 후 교체값 보존 |
| 의존성 누락 방지 | 세팅 스크립트가 미설치 시 **중단**하는 것 확인 |
| 롤백 실제 동작 | 가상 서버 A→B→A 전환 실측 |
| 상태·코드 분리 | 전환 후에도 사용자 자산 지문 일치 |

### ② 확인 중

- 배포 파이프라인 전체: 로컬 가상 서버 통과, **실제 가비아 서버는 미실행**
- 실제 SSH·systemd·nginx·certbot 경로 **미검증**
- 인터넷 경유 NAS 응답 속도: 이전 후에만 측정 가능

### ③ 승준님 결정 필요

| 항목 | 내용 |
|---|---|
| NAS 비밀번호 분리 | `nas.pw` 와 앱 비밀번호가 **동일** — 이전 전 마지막 교체 적기 |
| NAS IP 허용목록 | 가비아 서버 IP 추가 |
| 도메인 전환 방식 | hosts / `test.tsak.kr`(권장) / IP 직접 |
| 가비아 자격증명 | `GABIA_HOST` / `GABIA_USER` / `GABIA_SSH_KEY` (키 파일) |
| 백업 보존 정책 | 432개 무제한 → 일7+주4+월6 제안 |
| 가비아 포트 | 5071 은 샌드박스 사정. 서버 방화벽 확인 후 결정 |

## 자료 공유 규칙

메일·채팅으로 아래는 **보내지 않습니다.**

- 비밀번호 · 토큰 · API 키
- 실제 `.env` / `config.json` 원본
- SSH 개인키
- 운영 DB 덤프 · 대원 개인정보

절차와 키 **이름**만 공유하고, 값은 서버에 직접 넣는 방식으로 진행합니다.

## 한 가지만 분명히

**자료 제출과 배포 승인은 별개입니다.**

위 3가지(소스 버전·실행 방법·백업 절차)를 받았다고 해서 이전이 승인된 것은 아닙니다.
전환은 별도로 승인받은 뒤에 진행합니다.

지금 상태를 정확히 말하면 **"이전할 준비의 대부분은 끝났고, 실제 서버에서는 아직 아무것도 안 해봤다"** 입니다.
준비됐다고 말하려면 실제 서버에서 배포와 롤백을 한 번 돌려봐야 합니다.
