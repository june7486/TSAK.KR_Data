## 먼저 — 이 회신을 읽는 방법

요청하신 대로 **최종 소스 위치와 실행 안내를 맨 앞에** 두었습니다.

> **준비의 대부분은 끝났습니다. 그런데 실제 가비아 서버에서는 아직 아무것도 실행해 보지 못했습니다.**

이유는 하나입니다 — 가비아 서버 접속 정보(호스트·계정·SSH 키)를 아직 받지 못했습니다.

검증 도구는 이미 만들어 두었습니다. 접속 정보만 주시면 **배포와 롤백을 실제로 한 번
돌려서** ①로 승격시키겠습니다. 그전까지 "동작한다"고 말하지 않겠습니다.

**DNS·www.tsak.kr 포워딩·샌드박스·운영 데이터는 전혀 건드리지 않았습니다.**

### 파이썬 3.12 호환성 — 실측 결과

샌드박스는 **Python 3.13.14** 입니다. 3.12에서 도는지 확인한 방법과 결과입니다.

```
검사: ast.parse(source, feature_version=(3, N))  ← N = 8, 9, 10, 11, 12
결과: proxy_server.py  30,109줄  OK (3.8 ~ 3.12 전부)
      nas_lib.py          502줄  OK
      nas_gdrive.py       571줄  OK
      img_pipeline.py     243줄  OK
```

- **3.13 전용 문법 없음** — `type` 구문, `match`, `except*` 미사용
- **버전 의존 stdlib API 없음** — `rmtree(onexc=)`, `glob(root_dir=)`, `Path.walk()` 등 미사용
- **모듈 최상위 import는 표준 라이브러리뿐** — 외부 패키지는 모두 함수 내부에서 import

> ⚠️ **남은 위험을 정확히 말씀드립니다.**
> 위 검사는 **문법·API 정적 검사**입니다. 3.12 인터프리터에서 실제로 기동해 본 것은
> 아닙니다(샌드박스에 3.12가 없습니다). 다만 최상위 import가 stdlib뿐이라
> **기동 실패 가능성은 낮다**고 판단합니다. 시험 환경에서 첫 명령으로 확인해 주십시오.
> ```bash
> python3 -V                       # 3.12.x 확인
> python3 -c "import ast;ast.parse(open('proxy_server.py',encoding='utf-8').read())"
> ```

## 1-3. 웹만 배포하면 되는지 / 별도 API·백그라운드 작업이 필요한지

**웹 화면만으로는 동작하지 않습니다. 서버 프로세스 1개가 반드시 필요합니다.**

| 구성 | 필요 여부 | 설명 |
|---|---|---|
| 정적 웹 (`build/web`) | 필요 | Flutter 화면 |
| **API 서버 (`proxy_server.py`)** | **필수** | API 256개 + 정적 파일 서빙을 **한 프로세스가 겸함** |
| DBMS | 불필요 | 파일 기반 JSON (NAS) |
| 별도 배치·크론 | **불필요** | crontab 비어 있음(실측) |
| 메시지 큐·캐시 서버 | 불필요 | — |

### 서버 프로세스 — 실측값

```python
# proxy_server.py:30012
return ThreadingHTTPServer(("0.0.0.0", port), Handler)
```

| 항목 | 값 |
|---|---|
| 바인드 주소 | `0.0.0.0` (모든 인터페이스) |
| **포트** | **5071** |
| 포트 우선순위 | `TSAK_PORT` 환경변수 > `config.json` `port` > 기본 5071 |
| 상태 확인 경로 | **`GET /api/health`** |

> ### 요청하신 확인 사항 — "샌드박스 주소의 5071이 실제 수신 포트인가"
>
> **예. 실제 수신 포트입니다.** 추정이 아니라 실측입니다.
> ```
> $ ss -tlnp | grep 5071
> LISTEN 0 512 0.0.0.0:5071 0.0.0.0:* users:(("python3",pid=154538,fd=11))
>
> $ curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:5071/api/health
> 200
> ```
> 샌드박스 인그레스가 80/443 → 5071로 넘겨줄 뿐, **앱이 듣는 포트는 5071**입니다.
> 가비아에서도 nginx 업스트림을 `127.0.0.1:5071` 로 맞추시면 됩니다.
> (다른 포트를 쓰시려면 `TSAK_PORT` 만 바꾸면 되고, 코드 수정은 불필요합니다.)

### 프로세스 내부 백그라운드 스레드 (별도 프로세스 아님)

`python3 -u proxy_server.py` **하나** 안에서 다음이 돕니다. 별도로 띄울 것은 없습니다.

| 스레드 | 주기 | 역할 | 없으면 |
|---|---|---|---|
| `_serve_guard` | 상시 | `serve_forever` 예외 시 자동 재기동 | 요청 1건의 예외로 서버가 죽음 |
| `_mem_guard_loop` | 30초 | RSS 감시, 임계 초과 시 임시파일 정리 | 메모리 누적 시 OOM 위험 |
| `_hist_guard_loop` | 5초 | 집계 캐시 지연 쓰기 | 집계 반영이 늦어짐 |
| `_warm_bg` | 기동 1회 | JSON 캐시 예열 | 첫 요청이 느림 |
| `sess-save` | 변경 시 | 세션을 디스크에 저장 | 재기동 시 로그아웃됨 |

> 참고: 샌드박스에 `.watchdog.pid`(10월 13일, PID 46601)가 남아 있으나
> **이미 죽은 파일**입니다. 현재 상시 프로세스는 `proxy_server.py` **1개뿐**입니다(실측).

### 부수 확인 — 정적 경로 자동 탐색

`proxy_server.py` 는 `TSAK_STATIC_DIR` 이 없으면 아래 순서로 찾습니다.

## 1-4. `.env.example`

**파일**: `deploy/gabia/.env.example` (같은 저장소에 커밋되어 있습니다)

**값은 하나도 들어 있지 않습니다.** 이름·용도·필수 여부만 담았습니다.
총 30개 변수이며, **코드와 자동 대조해 누락 0건·오타 0건을 확인**했습니다.

### 필수 변수만 발췌

| 변수 | 필수 | 용도 | 없으면 |
|---|---|---|---|
| `TSAK_STATE_DIR` | **예**※ | 세션·업로드·캐시를 코드 밖에 보관 | **릴리스 교체·롤백 시 데이터 소실** |

| `TSAK_NAS_USER` | **예** | NAS 계정 | 기동 즉시 중단 |
| `TSAK_NAS_PW` | **예** | NAS 비밀번호 | 기동 즉시 중단 |

   다만 **롤백 때 데이터를 지키려면 반드시 지정**하십시오.

### 기동을 막는 검증 (실측)

필수값이 비면 **무엇이 없는지 이름을 불러주고** 종료합니다.

```
[config] 필수 설정이 없습니다: nas.base (또는 TSAK_NAS_BASE), nas.pw (또는 TSAK_NAS_PW),
  auth.masterHash (또는 TSAK_MASTER_PW)
  → config.json 을 두거나(권한 600), 환경변수로 주입하세요.
```

### 값이 들어가는 곳 (방식 A: 파일)

```bash
# 서버에서 직접 생성. 문서·메일·채팅으로 주고받지 않습니다.
umask 077
cat > ~/tsak/shared/config.json <<'JSON'
{
  "port": 5071,
  "backend": "auto",
  "nas":  { "base": "", "user": "", "pw": "", "base_path": "/92_Tiger_app_data/TSAK_인가자관리" },
  "auth": { "masterHash": "", "app": "" }
}
JSON
chmod 600 ~/tsak/shared/config.json
# 이후 값을 서버에서 직접 채웁니다 (heredoc·메일·문서 금지)
```

| 검증 항목 | 가짜 서버(리허설) | 가비아 실서버 |

**리허설에서 실제로 잡은 결함 5건** — 실서버였다면 사고가 났을 것들입니다.
이게 리허설을 먼저 한 이유입니다.

| # | 결함 | 결과 |
|---|---|---|
| 1 | 롤백 스크립트의 `$HOME` 이 따옴표 때문에 문자 그대로 전달 | **롤백이 한 번도 동작한 적 없었음.** 이번에 수정 |

## 2-3. NAS 가 자체서명 인증서 — 갱신 시 앱이 멈춥니다

**실측한 NAS 인증서 정보**

```

유효기간    : 2026-05-01 ~ 2027-05-02

**이번에 바꾼 것**: 종전 코드는 `ssl.CERT_NONE` — **인증서 검증을 아예 안 했습니다.**
샌드박스 안에서는 NAS가 사설망이라 견딜 만했지만, 가비아로 옮기면

**그래서 지문 고정(fingerprint pinning)으로 바꿨습니다.**
- 기본 `pin` 모드: 인증서 지문을 대조, 다르면 **즉시 연결 차단**
- 사설 자체서명서도 지문만 맞으면 통과 (공인 CA 불필요)
- 검증 완료: 정상 통과 ✅ / 지문 불일치 시 차단 ✅

> ⚠️ **2027-05-02 에 NAS 인증서가 만료됩니다.**
> 갱신하면 지문이 바뀌어 **앱 전체가 NAS 접속 실패로 멈춥니다.**
> 증상: 모든 화면이 "불러오기 실패".
> 갱신 시 `TSAK_NAS_CERT_SHA256` 에 새 지문을 넣고 재기동하면 됩니다.
> **이 사실을 운영 인수자에게 반드시 전달해 주십시오.** ②에 남겨 둡니다.

**DB(JSON)와 첨부파일을 각각 따로** 백업합니다.

# NAS에서 직접 받는 것이 정본입니다.
#   Synology DSM → File Station → /92_Tiger_app_data/TSAK_인가자관리/db

mkdir -p ~/backup/db
cd ~/tsak/current/api && python3 - <<'PY'
import sys, os, json
sys.path.insert(0, '.')
from nas_lib import NasClient
C = json.load(open(os.path.expanduser('~/tsak/shared/config.json'), encoding='utf-8'))

for f in c.list(base + '/db')['files']:
    if f.get('isdir'): continue
    open(os.path.join(out, f['name']), 'wb').write(c.read_bytes(base + '/db/' + f['name']))
    print('ok', f['name'])
PY

# ── (B) 첨부파일 ────────────────────────────────────────
#  NAS 폴더는 24MB 수준이라 DSM 에서 폴더째 다운로드가 가장 간단합니다.
#  (행사관리·photos 는 원본 용량이 큽니다 — 필요분만)

## 2-6. 최종 백업 이후 변경분 처리 — 제안

운영 데이터에 새 입력이 계속 들어오는 상황입니다. **두 단계로 나누어** 제안합니다.

**1단계 — 시험 환경 구축 중 (지금)**
- **입력 중단 불필요.** NAS가 정본이므로 시험 환경은 NAS를 그대로 읽습니다.
- 시험 중 데이터를 쓰면 **운영에 그대로 반영**됩니다. 그래서:
  - 시험은 **가상 데이터**로만 (요청하신 대로)
  - 실제 저장 시험은 **테스트 전용 폴더**에서 (③-5 와 연결)

**2단계 — 전환 시점 (승인 후)**

| 방식 | 내용 | 추천 |
|---|---|---|
| **A. 짧은 입력 동결** | 전환 30분 전 공지 → 입력 중단 → 최종 백업 → 전환 → 재개 | **권장** |
| B. 변경분 추적 | 최종 백업 이후 변경된 파일만 골라 재적용 | 위험 |
| C. 무중단 | NAS가 정본이므로 서버만 교체 | **불가** — 세션·업로드가 서버 로컬에 있음 |

**A를 권고하는 이유**: `merch_img_upload/` 와 `.sessions.json` 이 서버 로컬에 있어
"A 서버에서 올린 이미지"가 "B 서버"에는 없습니다. 동결 없이 옮기면
**동결 시점 이후 업로드가 유실**됩니다. 30분 동결이 가장 안전합니다.

**동결 절차 (30분)**
```
T-30  공지: "00:00~00:30 입력 중단"
T-0   관리자 화면 잠금(또는 공지만)
T+2   DB 백업 (38개)  +  업로드 백업 (merch_img_upload)
T+10  새 서버로 전환 (심볼릭링크 교체)
T+15  헬스·로그인·저장·업로드 확인
T+25  문제 시 즉시 롤백 (스크립트 1줄, 30초 내)
T+30  재개 공지
```
> 롤백은 `deploy_gabia.sh --rollback` 한 줄이고, 실측 30초 내 복구됩니다.

### ⚠️ CORS 허용 출처 — **여기가 유일한 실제 코드 변경 지점입니다**

```python
# proxy_server.py:17986
CORS_ALLOW_ORIGINS = [
    "https://tsak.kr",
    "https://www.tsak.kr",
    ".sandbox.novita.ai",
]
```

판정 방식은 `origin == a or origin.endswith(a)` 입니다. 그래서:
- `https://tsak.kr` → 통과 (목록에 있음)
- `https://www.tsak.kr` → 통과 (목록에 있음)
- **시험 도메인(예: `test.tsak.kr`)** → **차단됨**

> **시험 도메인을 쓰신다면 이 목록에 추가해야 합니다.**
> 단, **같은 출처**로 접속하면 CORS 검사 자체를 하지 않으므로
> `test.tsak.kr` 로 웹과 API를 **같이** 서비스하면 **수정 불필요**합니다.
> nginx에서 웹과 API를 같은 도메인으로 묶는 것을 권합니다 — 코드 수정이 0이 됩니다.

또한 `secure` 쿠키 판정은 `X-Forwarded-Proto` 헤더를 봅니다.
**nginx 설정에 이 헤더를 반드시 넣으십시오.** 없으면 쿠키에 `Secure` 가 안 붙습니다.
```nginx
proxy_set_header X-Forwarded-Proto $scheme;
proxy_set_header X-Real-IP $remote_addr;
```
