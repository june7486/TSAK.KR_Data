# 짧은 도메인(가비아) → 임시 샌드박스 앱 포워딩

## 지금 상태
- 앱(웹) 서비스 주소(QR 기준): `https://5071-i0wgdg3il1ohzxyvietj8-0e616f0a.sandbox.novita.ai`
- 앱: 설정 → "QR 공개 주소" = 위 주소로 저장됨 → 모든 개인/행사 QR이 이 주소로 생성됨
- 이 주소는 `?access=personal&no=415` 쿼리를 그대로 보존함(검증 완료)

## 목표
길고 못 외우는 샌드박스 주소 대신, 짧은 가비아 도메인으로 접속.

## ⚠️ 핵심: 가비아 포워딩은 반드시 "유동 포워딩"을 쓸 것
| 방식 | 주소창 | 쿼리(?access=...) | 비고 |
|---|---|---|---|
| 고정 포워딩(frame) | 내 도메인 유지 | ❌ 전달 안 됨 | ← 지금 tsak.kr이 이 방식이라 QR이 깨짐 |
| **유동 포워딩(redirect)** | 대상 주소로 변경 | ✅ 대체로 전달 | 가비아 공식 "로그인/새로고침에 안정적" 권장 |

### 방법 1 (가장 간단) — 유동 포워딩
1. 새 도메인 구매 → 관리툴 → **부가서비스 > 포워딩**
2. 방식 = **유동 포워딩(리다이렉트)**, 대상 URL = 위 샌드박스 주소
3. 테스트: `https://새도메인/?access=personal&no=415` → "인가자 편집" 뜨면 성공

### 방법 2 (100% 보장) — 리다이렉트 HTML 파일 호스팅
가비아 웹호스팅 루트의 index.html 을 `tigerscout_redirect/index.html` 로 교체.
(이 파일은 location.search + location.hash 를 100% 보존해 샌드박스로 넘김)
※ 이 경우 index.html 의 `APP_BASE` 를 샌드박스 주소로 맞춰둘 것.

### 방법 3 (호스팅 없이, PHP 가능 시)
```php
<?php
$q = $_SERVER['QUERY_STRING'] ?? '';
header('Location: https://샌드박스주소/'.($q ? "?$q" : ''));
```

## 검증 체크리스트
- [ ] `https://새도메인/?access=personal&no=415` → 인가자 편집 페이지 바로 표시
- [ ] 앱 하단 등에서 접속 시 정상 로그인 화면 표시
- [ ] 새로고침(F5) 시 로그인 풀리지 않음

## 주의
- 샌드박스 주소는 **임시**입니다(세션 만료 시 바뀔 수 있음). 영구 운영은 추후 NAS/Cloudflare 호스팅 필요.
- 포워딩 대상(샌드박스 주소)이 바뀌면, 앱 설정의 "QR 공개 주소"와 포워딩 대상도 함께 갱신해야 합니다.
