# 짧은 도메인(가비아) → 임시 샌드박스 앱 : QR 딥링크 대응

## 실측 결론 (2026-09-26 검증)
가비아 "포워딩"은 **고정/유동 모두 딥링크 파라미터를 전달하지 못한다.**
| 접속 | 최종 도착 | 쿼리 |
|---|---|---|
| `tsak.kr` | `...sandbox.novita.ai/` | ✅(루트라 무관) |
| `tsak.kr/?access=personal&no=415` | `...sandbox.novita.ai/` | ❌ 사라짐 |
| `tsak.kr/415` (경로) | 리다이렉트 안 됨(404) | ❌ |
| `tsak.kr/#access=...` (해시) | `...sandbox.novita.ai/` | ❌ 사라짐 |

→ 가비아 포워딩은 `meta refresh` 로 **고정 URL** 로 보내기 때문. 파라미터·경로·해시 전부 소실.

## 즉, 지금 상태
- **QR 자체는 이미 정상 동작**함: 각 QR 안에 **샌드박스 전체 주소 + ?access=...** 가 들어 있어,
  스캔하면 바로 정보수정 페이지로 연결됨. (짧은 주소를 "타이핑"하는 사람에게만 문제)
- 앱 설정 "QR 공개 주소" = 샌드박스 주소로 저장됨.

## 짧은 주소로 개인별 링크를 쓰고 싶다면 (택1)
### A) 가비아 웹호스팅에 리다이렉트 파일 올리기  ← 포워딩 끄고 웹호스팅 사용
1. 가비아 **웹호스팅(아이웹 등)** 신청 → 호스팅 루트에 아래 파일 업로드:
   `tigerscout_redirect/index.html` (location.search+hash 100% 보존)
2. `index.html` 의 `APP_BASE` = 샌드박스 주소 (이미 설정됨)
3. 포워딩은 **사용 안 함** (호스팅이 직접 응답)
→ `https://tsak.kr/?access=personal&no=415` → 정보수정 페이지로 바로 연결됨

### B) Cloudflare 무료 사용 (도메인 네임서버를 Cloudflare로)  ← 가장 안정적
- Cloudflare Worker(Redirect Rules)로 가비아 대신 처리. 쿼리 보존 100% + HTTPS 자동.
- 도메인 NS를 Cloudflare로 지정해야 함(가비아 관리툴 → 네임서버 변경).

### C) 짧은 주소를 "개인별"로 발급 (포워딩 그대로 둠)
- 개인별 QR은 그대로 사용(스캔), 사람이 타이핑할 일 없음.
